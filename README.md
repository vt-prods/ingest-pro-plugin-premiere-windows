# Ingest Pro Plugin for Premiere Pro

**Official website: [www.ingest-pro.com](https://www.ingest-pro.com/premiere)** · downloads, guides, pricing and support.

Ingest Pro builds an organised multicamera timeline directly inside Adobe Premiere Pro, without an intermediate XML file.

This is the official Windows release repository. The installable `.ccx` package is distributed through [GitHub Releases](https://github.com/vt-prods/ingest-pro-plugin-premiere-windows/releases/latest); the plugin source code is not included here.

## What it does

- Detects and groups footage by camera.
- Places cameras on separate video and audio tracks.
- Preserves real recording times and gaps between clips.
- Synchronizes cameras by analysing their audio, down to the frame.
- Optionally applies colour labels, closes inactive gaps and creates one track per clip.
- Verifies the resulting positions in the Premiere Pro timeline.

## Requirements

- Windows 10 or 11.
- Adobe Premiere Pro 26.2 or later.
- Internet connection for licence activation and periodic subscription validation.

The plugin works only inside Premiere Pro. For DaVinci Resolve, use the separate Ingest Pro Desktop application, which exports an XML timeline.

## Installation

1. Download `IngestProPlugin-Premiere-Windows.ccx` from [Releases](https://github.com/vt-prods/ingest-pro-plugin-premiere-windows/releases/latest).
2. Open the package with Creative Cloud or your Adobe plugin installer.
3. Launch Premiere Pro, open the Ingest Pro panel and start the trial or activate your subscription licence.
