# Ingest Pro Plugin Premiere Windows

Official release repository for the Windows plugin for Adobe Premiere Pro.

The plugin is distributed through GitHub Releases. Source code is not included in this repository.

## Requirements

- Windows 10 or 11
- Adobe Premiere Pro 26.2 or later

## Features

- Automatic multicamera timeline organization
- Real temporal spacing between clips
- Audio synchronization to frame
- Color labels, gap closing, and clip-track mode
